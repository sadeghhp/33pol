            Throttling
            
Rate limits

            
Default tier and plan tiers (RPM, burst, max concurrent streams). Stored in the database and applied without a restart. A tier is a tenant-wide budget — every API key a tenant holds draws on the same one.

            

              
Default

              
The tier every tenant gets unless a plan (or a tenant override) matches them.

              
Plan slug

              
Name of a plan, such as standard. Tenants on that plan use the tier on this row instead of the default.

              
RPM

              
Requests per minute the tenant may keep up over time — the sustained ceiling. Minimum 1; there is no “unlimited” value.

              
Burst

              
The maximum number of extra requests allowed in a short period before rate limiting kicks in. A tenant that has been idle can send RPM + Burst requests back-to-back, then drops to the RPM pace. 0 means no spike allowance beyond one minute’s worth of requests.

              
Max streams

              
Streaming responses the tenant may hold open at the same time. 0 means unlimited, not “streaming off” — there is no per-tier way to refuse streaming.

Rate-limit usage

            

              Live admission counters: requests per user and model, how each sits against the limit actually in force, and where
              limits are being hit. In-memory and reset by a restart — durable spend per tenant and model lives in the
              billing rollups.
            

            

              
              
              
            

            

            
          


          
          

            Browser origins
            
CORS allowed origins

            

              Browser SPA origins that may call /v1/* in Production (exact match: no path, no trailing slash;
              localhost ≠ 127.0.0.1). Applied without a restart. For Docker durability across image
              redeploys, also set GATEWAY_CORS_ALLOWED_ORIGIN_* via docker-compose.cors.override.example.yml.
